## One-way points (protocol 10)

- Rule books move into the control ledger (D108). Once every control member declared protocol 10 and the installation is contracted, the first rule command commits one replicated marker (`rules:ledger`) and every voter moves the rule books and the rule outbox out of its control state blob into ledger tables. The marker cannot be undone: a protocol-9 member or learner is refused afterwards (`layout_incompatible`), and a voter does not go back to the previous release. See docs/operations/upgrade.md, "Rule books move into the ledger". A diagnostic build reports `rule_layout` and `rule_marker_index`.
