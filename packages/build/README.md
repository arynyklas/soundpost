# @soundpost/build

Build-time release integration for Soundpost: immutable debug identities for generated assets and their source maps, and private upload of the maps to the C07 artifact service. Logical package name (C09); no registry reservation is claimed.

```ts
// vite.config.ts (Vite 7.x)
import {soundpostVite} from "@soundpost/build";
export default {plugins: [soundpostVite({
  org, project, source, build,                       // registered 32-hex identities
  upload: {endpoint: "https://soundpost.example", credential: () => process.env.SOUNDPOST_ARTIFACT_WRITE_CREDENTIAL!},
})]};
```

```js
// webpack.config.js (webpack 5.x)
plugins: [soundpostWebpack({org, project, source, build, upload: {endpoint, credential}})]
```

Exact C09 surface: `uploadArtifacts(manifest: ArtifactManifest, files: AsyncIterable<ArtifactFile>, config: UploadConfig): Promise<ArtifactReceipt>`; `createUploadConfig({endpoint, credential})` seals the config.

## What the plugin does

1. Forces a **private** map (`hidden`/`hidden-source-map`): the emitted bundle never carries a `sourceMappingURL`, so nothing can fetch a map at runtime. Inline maps are rejected.
2. Derives a **debug ID** from the generated bytes (SHA-256, first 32 hex), appends `//# debugId=<id>` to the asset and `debugId` to the map. The ID is content-bound, so it is identical across a release rename or a rebuild; the `build` ID is the one you configure and is never invented.
3. Normalizes map `sources` to project-relative paths (`webpack://ns/./x.js`, `../../x.ts` relative to the map become `x.js`/`x.ts`; anything outside the project root becomes `external/<name>`).
4. **Source content is absent by default**: `sourcesContent` is stripped from the emitted map and from the upload. `includeSourceContent: true` sets the manifest's `source_content` grant flag and requires every source to have content; the backend still needs its explicit grant and retention policy.
5. Writes the final bytes back to disk, so the manifest's `generated_sha256`/`map_sha256` are the hashes of exactly the files you deploy/keep and upload.
6. Uploads one multipart request per JS asset (`POST /api/v1/artifacts`, `manifest` field then the map as `file`) with `Authorization: Bearer <private artifact-write credential>`.

## Limits and rejections (before any byte is sent)

C07 limits are mirrored locally: 32 MiB expanded bundle, 1024 files (source entries included), map nesting depth 8, path ≤ 4096 bytes. Reasons are closed `ArtifactError.code` values: `map_missing`, `map_hash_mismatch`, `generated_missing`, `generated_hash_mismatch`, `map_indexed` (indexed/sectioned maps, including recursive sections), `map_path_unsafe` (absolute, `..`, backslash, scheme sources), `path_invalid`, `map_too_large`, `map_too_deep`, `too_many_files`, `bundle_too_large`, `map_invalid`, `source_content_unexpected`, `source_content_missing`, and transport codes `upload_rejected` (HTTP status only), `upload_failed`, `receipt_invalid`. A JS asset without a map fails the build visibly. Bundlers overwrite `error.code`, so plugin failures expose the reason as `error.reason` on a `SoundpostArtifactError`.

Symbolication is a backend concern (C07): a missing or mismatched map yields a visible reason and the original sanitized frame there. This package never fetches maps at runtime.

## Credential handling

The upload credential is the private artifact-write credential, never the browser source key. It is held only in a closure: `JSON.stringify`, `util.inspect` and string conversion of the plugin or the upload config cannot echo it; errors carry a code (and an HTTP status), never a response body; redirects are not followed; plaintext endpoints are accepted only for loopback; credentials containing whitespace/control characters are rejected before use. The plugin injects nothing into the bundle.

## Not delivered here

Getter-free creation/throw-site evidence for SDK-captured errors needs a runtime evidence API in `@soundpost/core` plus a build transform; this package assigns the identities that evidence would reference but does not instrument code.
